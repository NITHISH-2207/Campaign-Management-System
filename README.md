# ChangeWave - Social Campaign Analytics Platform

## Overview
ChangeWave is a comprehensive platform for creating, managing, and measuring the impact of social awareness campaigns.

## Features
- 📊 Real-time engagement analytics and sentiment analysis
- 📚 Educational content library with interactive modules
- 📈 Impact tracking with before/after community surveys

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT
